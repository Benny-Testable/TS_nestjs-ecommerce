# Password and credential policy

## Users of the API

- Minimum: non-empty password at registration (`CreateUserDto`).
- Stored only as bcrypt hashes.
- Institutional policy should require length >= 12 and a password manager; that rule is **not** enforced in code today.

## Administrators and services

- `JWT_SECRET` and `DATABASE_PASSWORD` are generated by Terraform `random_password` and stored in Secrets Manager.
- Local `src/common/envs/*.env` values are development fixtures only.
- Rotate JWT secret by replacing the secret version and redeploying ECS (invalidates all sessions).
- Do not share Admin accounts; use `POST /role/assign` per person.
