# Compliance documentation

This NestJS API is an ecommerce backend (`User`, `Product`, `Role`, JWT sessions). It is **not** a student information system.

- `ferpa/` describes how education-record rules would apply if an educational institution used this API to process student-linked accounts (for example a campus store). Documentation is not a legal determination of FERPA applicability or compliance.
- `soc2/` describes Trust Services Criteria-oriented controls mapped to this codebase and `infra/terraform`. Presence of these files is not a SOC 2 report.

Implemented technical controls live in `src/` and `infra/`. Organizational process controls are labeled as such in each document.
